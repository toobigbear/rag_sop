## 六、SOFA评分体系（评分页签）
| 字段 | 含义 | 说明 |
|---|---|---|
| SOFA评分 | 序贯器官衰竭评估 | 总分=呼吸+凝血+肝+循环+神经+肾 |
| 呼吸评分 | 基于PaO2/FiO2 | 0–4分 |
| PLT评分 | 凝血(血小板) | 0–4分 |
| 肝脏评分 | 基于胆红素 | 0–4分 |
| 循环评分 | 基于MAP/血管活性药 | 0–4分 |
| 神经评分 | 基于GCS | 0–4分 |
| 泌尿评分 | 基于尿量/肌酐 | 0–4分 |
| GCS评分 | 格拉斯哥昏迷评分 | 3–15 |
| 尿量 | 每日尿量 | ml |
